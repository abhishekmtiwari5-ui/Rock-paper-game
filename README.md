# Rock-paper-game
Rock-paper game using javascript
Specifications of this Game are listed below:-
1. It display's ROUND NUMBER, YOUR CHOICE, BRONO'S CHOICE on the blue color head.
2. Then, at the bottom it shows button to start the round at starting and after clicking it it changes to NEXT ROUND button.
3. On clicking the START THE ROUND button it displays the icons for your choice(ROCK, PAPER, SCISSOR).
4. At the bottom it displays both player's SCORE.
5. There are 6 rounds in it and after 6th round it displays the MATCH WINNER.
